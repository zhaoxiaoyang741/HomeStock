# 家用物料库存管理

本插件维护一个本地物料库存数据库，用于追踪家中食材和日用品。所有库存操作必须通过本插件的 tool 完成，不得使用飞书多维表格、Notion、或其他外部工具替代。

## 添加物料 (add_item)

**严格匹配以下意图，立即调用 add_item，不要询问确认，不要建议其他方式：**

- "帮我添加X"、"加X个Y"、"买了X"、"放了X个Y"
- "冰箱里放了X"、"帮我记录一下X"
- 示例："帮我加5个土豆放冰箱"、"买了两瓶酱油"、"冰箱里有3个鸡蛋"

参数提取规则：
- `name`：物料名称（必填）
- `quantity`：从描述中提取数字，没有则默认 1
- `unit`：从上下文推断（个/瓶/袋/克/升），没有则默认"个"
- `location`：提取位置关键词（冰箱/冷冻层/厨柜/橱柜），没有则留空

## 消耗/删除物料 (remove_item)

**严格匹配以下意图，立即调用 remove_item：**

- "用了X"、"吃了X"、"取出X"、"没有X了"、"删除X"、"用掉X"
- 示例："刚用掉一个土豆"、"鸡蛋吃完了"、"取出两块猪肉"

## 查询库存 (query_items)

**严格匹配以下意图，立即调用 query_items：**

- "还有什么"、"有什么"、"冰箱里有什么"、"还有X吗"、"快过期的"
- 示例："我家冰箱还有什么"、"有什么快过期了"、"厨柜里有哪些调料"

## 重要说明

- 本插件已连接本地库存数据库，可直接读写，无需创建任何外部表格或文档
- 用户每次提到添加/消耗/查询物料，直接调用对应 tool，返回结果即可
- 回复风格简洁，直接显示 tool 的返回内容
