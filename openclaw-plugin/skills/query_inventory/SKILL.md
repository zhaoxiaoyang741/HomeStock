本技能对应 `query_inventory` 工具。识别到查询库存、按位置查看、按分类查看、按关键字搜索或查看临期批次时，直接调用工具。

只要用户是在问“现在有什么”“目前还剩什么”“某个位置里有什么”“家里还有没有某样东西”，就优先调用工具，不要改成建议用户建清单、写文件、手工记录。
即使消息里带有“回复某人：”“帮我回一句：”“转告一下：”这类转述，也要先把库存查询识别出来，再调用工具。

## 触发场景
- “目前冰箱里有什么”
- “现在冰箱里还有什么”
- “冰箱里有什么”
- “冰箱里还有什么”
- “回复 坨坨他哥：冰箱里还有什么”
- “帮我回一句，冰箱里还有什么”
- “家里还有什么调料”
- “目前家里还有什么吃的”
- “查一下快过期的”
- “还有没有土豆”
- “还剩啥”
- “还有啥”
- “查库存”
- “厨房里还有什么零食”

## 参数提取
- `location`：位置关键词，如“冰箱”“冷冻层”“厨房”。
- `category`：分类名，如“调料”“蔬菜”“零食”。
- `expiring_soon`：用户提到“快过期”“临期”“即将过期”时传 `true`。
- `keyword`：名称或规格关键词，如“土豆”“牛奶”。

## 执行规则
- 默认查询物料汇总。
- 只有明确是看临期时，才查询批次列表。
- “目前/现在/还有什么/里有什么”这类问法默认就是库存查询，不要当成闲聊或记事需求。
- “还有没有土豆”这类表达优先把“土豆”识别为 `keyword`。
- “回复某人：冰箱里还有什么”这类消息，忽略“回复某人”前缀，保留真正的库存查询内容。
- 若查询过程失败，工具会先检查 HomeStock 服务健康状态，再返回更准确的错误信息。

## 禁止行为
- 不要回复“我先帮你建个清单”“我可以写到文件里”“不等后端了”这类内容。
- 不要在已经安装库存插件的前提下，把库存查询改造成记事或备忘录场景。
- 不要说“无法确认是否还有其他物品”“我猜测还有”“大概还有这些”这类臆测性故障文案。

## 示例
输入：
```text
目前冰箱里有什么
```

工具参数：
```json
{
  "location": "冰箱"
}
```

输入：
```text
冰箱里还有什么调料
```

工具参数：
```json
{
  "location": "冰箱",
  "category": "调料"
}
```

输入：
```text
查一下快过期的牛奶
```

工具参数：
```json
{
  "keyword": "牛奶",
  "expiring_soon": true
}
```

Slash command：
```text
/query_inventory 冰箱
/query_inventory 冰箱 调料
/query_inventory expiring
```

若自然语言没有稳定命中，本技能的正式兜底入口就是上面的 slash command，不要发明新的临时命令。
